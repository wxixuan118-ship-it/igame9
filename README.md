# igame9.ai — static game site

> This repo also contains the **game directory** app in [`directory/`](directory/README.md), deployed separately and served at `igame9.ai/directory` through `serve.mjs` (set `DIRECTORY_ORIGIN`). The games site itself is unchanged: `npm start` builds and serves `dist/`.

One game page per target keyword plus a hub page (`/`). Pure static HTML generated by a zero-dependency Node script.

```
data/site.mjs            site config + categories (hub order)
data/pages/<slug>.mjs    one file per game page (content, SEO, which engine to run)
src/templates/           layout, game page, hub templates (template literals)
src/assets/css/site.css  all styles, including the in-game .ig-* UI kit
src/assets/js/shell.js   game shell: mounts engines, sound, fullscreen, keys, storage
src/assets/js/games/     one file per game engine (IGAME.register)
src/assets/img/thumbs/   16:9 SVG thumbnails, <slug>.svg (fallback is generated)
src/assets/img/og/       1200×630 PNG share images (npm run og)
build.mjs → dist/        npm run build
serve.mjs                npm run serve → http://localhost:4173
```

## Commands

```bash
npm run build      # validate data + write dist/
npm run serve      # preview dist/ on :4173 (no caching)
npm start          # production: build, then serve dist/ on $PORT (default 3000)
npm run og         # render og PNGs from thumbnails with headless Chrome
npm run check      # headless-Chrome smoke test of every page (JS errors)
node scripts/audit-all.mjs [outDir] [slug…]   # on-page SEO audit of every built page (onpage-audit skill, target ≥95)
```

Deploy: on AnySites (Node) there is no Dockerfile — the generated one runs `npm start`, which builds `dist/` and serves it on `$PORT` (3000) with gzip and cache headers; no build command is needed. Alternatively upload `dist/` to any static host (Cloudflare Pages, Netlify, Nginx). URLs are `/<slug>/`. No database or object storage is used.

## Page data (`data/pages/<slug>.mjs`)

```js
export default {
  slug: 'drift-boss',               // URL → /drift-boss/
  keyword: 'Drift Boss',            // target keyword
  volume: 1000, kd: 21,             // used for ordering on the hub
  category: 'racing',               // idle | racing | runner | puzzle | action
  engine: 'edge-drift',             // src/assets/js/games/edge-drift.js
  variant: 'default',               // passed to the engine (themes / level sets)
  embedUrl: '',                     // set to a LICENSED iframe URL to replace the built-in game
  embedCredit: '',                  // e.g. 'MarketJS' — shown when embedUrl is set
  game: {
    title: 'Edge Drift',            // name of the built-in original game
    hint: 'Hold to drift right, release to swing left',   // player bar hint
    saves: 'Best score & coins saved in your browser',
    playMode: 'SinglePlayer',
    controls: [{ action: 'Drift right', keyboard: ['Space', '→'], mouse: 'Hold left button', touch: 'Hold anywhere' }],
  },
  seo: { title, description, h1, lede, card, updated: '2026-10-02' },
  original: { name, developer, released, genre, platforms },   // facts about the game the keyword refers to
  intro: ['<p>…</p>', '<p>…</p>'],
  howToPlay: ['step (HTML ok)', …],
  tips: ['tip (HTML ok)', …],
  sections: [{ id: 'about', h2: '…', html: '<p>…</p>' }],
  faq: [{ q: '…', a: '…' }],
  related: ['drift-hunters', …],      // slugs, up to 6 (auto-filled otherwise)
};
```

Swapping in an official embed: set `embedUrl` (and `embedCredit`) and rebuild. The page then shows a click-to-play cover that loads the iframe; the built-in engine script is not loaded.

## Game engine contract

Each engine is a plain script (no modules, no external assets) that registers a factory:

```js
IGAME.register('edge-drift', function (ctx) {
  // ctx.root       – empty, position:relative element filling the frame. Build canvas/DOM inside it.
  // ctx.variant    – string from page data
  // ctx.title      – in-game title
  // ctx.store      – {get(key, def), set(key, val), remove(key)} JSON localStorage, namespaced per page, never throws
  // ctx.sfx(name)  – click tick coin buy jump slide hit shoot merge match error win lose levelup boost skid explode pop
  //                  or ctx.sfx({f, f2, d, type, v, delay}) for a custom tone
  // ctx.onKey(fn)  – fn(code, isDown, event) for KeyboardEvent.code; only fires while this game is active
  //                  (user clicked into it). Arrows/Space default actions are prevented automatically.
  // ctx.captureKeys(['KeyW', …]) – also prevent defaults for these codes
  // ctx.keys       – live map code → bool of currently held keys
  // ctx.isActive() / ctx.focus()
  // ctx.isTouch, ctx.params (URLSearchParams), ctx.debug (true with ?debug=1)
  const view = IGAME.createCanvas(ctx.root, { onResize(w, h) {} }); // view.ctx draws in CSS px; view.width/height
  const loop = IGAME.loop(function (dt, t) { /* dt seconds, ≤ 0.05 */ });
  loop.start();
  return {
    pause() { loop.stop(); },
    resume() { loop.start(); },
    destroy() { loop.stop(); view.destroy(); /* remove every listener you added to window/document */ },
  };
});
```

Helpers: `IGAME.ui.overlay(root, {title, text, html, buttons:[{label, primary, onClick}]})`, `IGAME.ui.toast(root, text)`, `IGAME.ui.el(tag, cls, html)`, `IGAME.fmt(n)` (1.2K, 3.4M…), `IGAME.fmtTime(sec)`.

Rules: must work at any aspect ratio (16:9 desktop, 4:5 phone, fullscreen), with mouse, keyboard and touch; restart button calls `destroy()` then remounts, so clean up everything; idle games should measure real elapsed time (`Date.now()`) for offline progress.

Notes: fullscreen applies to the whole `.player` (frame + toolbar), so nothing overlays the game and the toolbar button exits it (Esc also exits the CSS fallback). The shell prevents the default action of arrows/Space while a game is active, so Space never "clicks" a focused overlay button — handle it in `ctx.onKey` if you want it to.

## Debugging

Append `?debug=1` to any page URL to print engine errors on screen.
